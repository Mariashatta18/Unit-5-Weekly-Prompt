# Unit 5 Weekly Prompt – Chapter 11

**Question: Explain how testing your written code improves your written code.**

Testing is an important part of software development because it helps programmers make sure their code works correctly before it is used in a larger program. Even when code looks correct, there can still be small mistakes that are difficult to notice. Testing gives us a way to compare the result we expect with the result the program actually produces.

Testing also improves code by helping programmers find problems early. For example, a function may work correctly with one input but fail when a different value is entered. Testing the function with different inputs makes it easier to identify these problems and understand what needs to be fixed. It also encourages programmers to write functions and classes that are organized and focused on a clear purpose.

Another important benefit is being able to test the code again after making changes. When part of a program is updated, previous tests can be run again to make sure the new changes did not cause problems in code that was already working. Overall, testing makes code more reliable, organized, and easier to maintain.
